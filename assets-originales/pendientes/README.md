# Recursos pendientes de integración

El propietario entregó `human+character+3d+model+reposo.glb` para usar su animación `idle` cuando el personaje esté parado. Se conserva íntegro, comprimido con GZIP sin pérdida. El archivo tiene un esqueleto de 65 huesos y una animación de reposo de 15,33 segundos.

**No está integrado en el juego.** El propietario indicó que compartirá otros recursos antes de continuar con el código. No se ha modificado el personaje activo ni generado otra compilación.

`reposo.json` registra las sumas SHA-256, el tamaño original y los datos del clip. Descomprimir el archivo `.glb.gz` recupera exactamente el GLB entregado.
