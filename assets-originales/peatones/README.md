# Personajes originales

Siete archivos GLB entregados por el usuario, conservados sin modificar mediante compresión gzip dividida en partes. El manifiesto registra el nombre original, tamaño y SHA-256 de cada archivo.

Para reconstruirlos: `python3 nivel-01/scripts/restore-pedestrians.py`. Las versiones optimizadas para Android se preparan con `node nivel-01/scripts/prepare-pedestrians.mjs assets-originales/peatones/restaurados`.

Los 38 clips originales permanecen dentro de sus respectivos personajes. Este archivo de originales no cambia por sí solo la APK.
