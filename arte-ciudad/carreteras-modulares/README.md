# Tramos de carretera para modelado 3D

Tres referencias independientes para construir la ciudad con piezas más sencillas y reutilizables. El usuario pidió sustituir la idea de una red completa con muchas manzanas por tramos largos de carretera.

| Imagen | Diseño |
| --- | --- |
| [01-avenida-recta.png](01-avenida-recta.png) | Avenida recta de cuatro carriles, aceras, paso peatonal, semáforos y señales de velocidad. |
| [02-cruce-semaforos.png](02-cruce-semaforos.png) | Avenida larga con un único cruce en T, pasos peatonales y semáforos. |
| [03-avenida-curva.png](03-avenida-curva.png) | Avenida curva con aceras, señales de curva y velocidad, paso peatonal y semáforos. |

PNG con transparencia real, sin vehículos, edificios, personas ni terreno de fondo. Vista elevada para apreciar el pavimento, las aceras y los elementos verticales. Los extremos completos permiten usar cada imagen como referencia de una pieza conectable; las dimensiones y uniones deberán ajustarse en el modelado 3D.

`prompts.json` conserva las indicaciones y el ajuste de encuadre de la avenida recta. `manifest.json` registra resolución, tamaño y sumas de comprobación.
